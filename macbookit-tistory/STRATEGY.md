# 맥부킷 (macbookit / doonablog.tistory.com) 운영 전략

> **플랫폼**: 티스토리 (애드센스 + 카카오 애드핏)
> **니치**: Mac/Apple 실사용자 (입문~중급)
> **현 상태**: 운영 중, 신규~안정기 사이
> **목표 6개월차**: 일 방문 1,000+, 월 50~80만 원 (애드센스 + 쿠팡파트너스)

---

## 1. 왜 Mac 니치인가

| 항목 | Mac 니치 | 일반 IT |
|------|---------|---------|
| 애드센스 CPC | **300~800원** (Apple 광고주 多) | 100~300원 |
| 검색 의도 | Commercial 多 (구매 직전 검색) | Informational |
| 구글 우대 | 강함 (튜토리얼·리뷰형) | 보통 |
| 다음 우대 | 약함 | 약함 |
| 쿠팡 전환 | 매우 높음 (액세서리·도크·케이스) | 보통 |

**핵심**: Mac 사용자는 **구매력 강하고 검색 정확함** → 단가 + 전환 모두 좋음.

> 🔴 **정정 (2026-08-30 실측) — 위 CPC 표는 근거 없는 추정치였다.**
> 애드센스 API 28일 실측(`cli.py adsense report --days 28`, 계정 everywhere/pub-2213…):
> **수익 $0.28 · 노출 1,731 · 클릭 19 → 실효 CPC 약 $0.0147 ≈ 20원.**
> 위 표가 내건 **「300~800원」의 1/15~1/40** 이다. 참고로 dokyungja 계정은 28일 $0.01(클릭 2).
>
> **니치 선택 근거를 CPC 로 삼는 서술은 폐기한다.** Mac 니치를 유지할 이유는 남아 있지만
> (구글이 이미 준 순위·계열 유일 dofollow 자산·카플레이 53개 쿼리), 그 이유는 **단가가 아니라
> 트래픽과 링크 자산**이다. 병목은 트래픽이 아니라 **단가**이므로, 수익 목표
> (「6개월차 월 50~80만 원」)는 애드센스만으로는 도달 불가다 —
> 쿠팡파트너스·제휴 전환이 실질 경로다. 이 목표치는 실측으로 다시 세울 것.
>
> ⚠️ 다음 세션 주의: 이 문서를 읽고 「Mac 은 CPC 가 높으니까」로 의사결정하지 말 것.

## 3. 발행 카테고리 (3개 허브)

기존 스킬에 정의된 허브 구조 유지·확장.

| 허브 | 월 발행 | 검색 의도 | 수익 모델 |
|------|--------|----------|----------|
| **A. 세팅 허브** (초기 설정·환경구성) | 3편 | Informational | 애드센스 |
| **B. 백업·동기화 허브** | 2편 | Informational | 애드센스 + iCloud 제휴 |
| **C. 생산성·앱 추천 허브** | 3편 | Commercial | **쿠팡 + 앱 제휴 (Setapp 등)** |

**총 월 8편 (주 2편)**. 깊이 있는 1편이 가벼운 5편보다 효과적.

## 4. 글 1편 작성 표준 (4시간/편)

### 분량
- **본문 2,000~3,500자**
- 본인 Mac 스크린샷 6~10장 (필수)
- 단축키 표 1개+
- 비교 표 1개 (Commercial 글)

### 구조 (스킬 파일 준수)
- 도입부 (3문장 내 문제→해결 약속)
- H2 4개 여정 순서
- 요약 박스(Top Picks) 상단 + CTA
- 비교 표 또는 비교 카드
- FAQ 3~5개 (스키마 대응)
- 내부링크 카드 2~3곳

### 본인 1차 데이터
- 직접 사용 스크린샷 (필수, 스톡 X)
- "내 환경: M2 Air, macOS 14.x" 명시
- 실패 사례 1줄 ("이 방법은 내 환경에서 안 됨") — E-E-A-T

## 5. 키워드 발굴 워크플로우

### 황금 키워드 패턴 (Mac 특화)
- **"맥북 + 문제 + 해결"** — "맥북 배터리 광속 소모 해결"
- **"앱 + vs + 비교"** — "Notion vs Bear vs Obsidian"
- **"기능 + 단축키 모음"**
- **"신제품 + 추천 액세서리"** (쿠팡 전환 ↑)
- **"macOS 버전 + 새 기능"** (시즌성 — WWDC 직후)

### 도구 순서
1. **GSC 기회 키워드** (11~30위) — 매주 5~10개 발굴
2. **블랙키위**: "맥북" 시드 → 황금키워드
3. **Google Keyword Planner**: 검색량 우회 해킹 (Max CPC 100,000원)
4. **AI 발굴 프롬프트**:
   ```
   Mac/Apple 사용자가 실제로 검색하는 롱테일 키워드 30개. 조건:
   - 신규 macOS/iOS 출시 후 1~3개월 내 검색 폭증 키워드
   - "어떻게/왜/안 됨/해결" 등 문제 해결형 70%
   - "추천/비교" 30% (쿠팡 연계)
   각 옆에 (1) 검색 의도 (2) 쿠팡 추천 상품 가능 여부
   ```
5. **Reddit r/mac, r/MacOS, 클리앙 맥** — "내가 못 푸는 문제" 발굴

## 6. 광고 + 쿠팡 배치 (수익 최적화)

### 광고
- 카카오 애드핏 + 구글 애드센스 **동시 운영 가능** (티스토리 정책 허용)
- 본문 상단(타이틀 직후) 1개 + H2 사이 2개 + 본문 하단 1개
- Auto Ads OFF, 수동 배치만

### 쿠팡파트너스 (생산성·세팅 카테고리 핵심)
- 글당 카드 2~3개 (5개 초과 X)
- **최상단 명시 필수** (스킬 파일 양식 사용):
  > "이 글에는 쿠팡 파트너스 활동의 일환으로 일정액의 수수료를 제공받을 수 있습니다."
- 추천 상품: USB-C 도크, 외장 SSD, 키보드, 마우스, 케이스 (전환율 5~8%)

## 8. 안티패턴

1. **공식 도움말 번역**: 트래픽 0 + Site Reputation Abuse 위험
2. **신제품 출시 24시간 내 글**: 깊이 없음 → HCU 페널티
3. **자동완성으로 양산**: 1주일 후 색인 누락
4. **리뷰 글에 본인 사용 경험 없음**: 즉시 신뢰 깎임
5. **짧은 글 (800자 미만)**: 티스토리 저품질 위험
6. **광고 5개 초과**: 애드센스 정책 위반
