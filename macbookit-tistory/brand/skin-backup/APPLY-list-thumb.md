## ① html 탭 — 한 줄 찾아 바꾸기

`C230x300` 이 html 에 **두 곳** 있다. 바꾸는 건 **`_article_rep_thumbnail_raw_url_` 가 붙은 쪽 하나뿐**이다.
(다른 하나는 `_cover_item_thumbnail_` = 홈 커버 모듈이라 건드리지 않는다.)

html 편집기에서 **아래 문자열을 검색**한다 (스킨 전체에서 이 한 곳뿐이다 — 확인함).

```
C230x300.fwebp.q85/?fname=[##_article_rep_thumbnail_raw_url_##]
```

찾았으면 그 자리의 **`C230x300` 을 `C300x300` 으로** 만 바꾼다. 나머지는 손대지 않는다.

```
C300x300.fwebp.q85/?fname=[##_article_rep_thumbnail_raw_url_##]
```

> `<img>` 태그가 세 줄에 걸쳐 있어 태그 통째로 찾으면 공백 때문에 안 걸린다.
> 위 한 줄짜리 문자열로 찾는 게 확실하다.

왜: `C230x300` 은 23:30 **세로 크롭**이라 1:1 커버의 좌우가 잘린다.
`C300x300` 은 실제로 200 을 반환하는 것을 확인했다(6,982B → 7,866B).

## ② CSS 탭 — 맨 아래에 붙여넣기

`Blog-strategy/system/list-index-thumb.css` 내용을 **기존 `--unify-index` 블록 아래**에 붙인다.
(순서가 중요하다 — 같은 특정도라 나중에 온 쪽이 이긴다. 기존 블록의
`.post-item .thum { display:none !important }` 를 이 블록이 덮는다.)

## ③ 적용 후 확인

```bash
curl -sL -A 'Mozilla/5.0' https://doonablog.tistory.com/ \
  | grep -o 'thumb/C[0-9]*x[0-9]*' | sort | uniq -c
# → C300x300 이 목록 개수만큼 나와야 한다
```
